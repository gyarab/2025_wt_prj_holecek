O Projektu KebabTracker

🎯 Náš Cíl

KebabTracker je komunita milovníků kvalitních kebabů. Naše databáze obsahuje recenze a informace o nejlepších kebabárnách v České republice. Slouží jako průvodce pro všechny, kdo hledají ten nejlepší kebab ve svém okolí.

📍 Mapy Kebabáren

Najděte nejbližší kebabárnu v seznamu dostupných podniků s informacemi o otevírací dobu a kontaktech.

⭐ Hodnocení

Čtěte a píšete recenze s detailním hodnocením kvality masa a dalších aspektů kebábů.

🔗 API

Přístup k našemu veřejnému API pro vývojáře. Vyzkoušejte si API Playground na webu.

🚀 Technologie

KebabTracker je vytvořen s moderními technologiemi:

  • Backend: Django 6.0 + Django Ninja (REST API)
  • Frontend: Vue 3 + Vite
  • Databáze: SQLite
  • CORS: django-cors-headers pro bezpečnost
